# cleanse

## Що це

Лендинг для **Cleanse** — продукт-сторінка (брендинг, офер, конверсійні елементи).

Статична HTML-сторінка (без збирача, без залежностей).

## Як переглянути

1. Відкрити `index.html` напряму у браузері, **або**
2. Запустити локальний сервер:
   ```bash
   python3 -m http.server 8000
   ```
   і відвідати `http://localhost:8000/`

## Структура

- `index.html` — основна сторінка
- `css/` — стилі
- `fonts/` — кастомні шрифти
- `icons/` — іконки
- `img/` — зображення
